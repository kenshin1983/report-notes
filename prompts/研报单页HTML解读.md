# 研报单页 HTML 解读

将 PDF 全文核心内容翻译为简体中文，整合浓缩成一个单文件 HTML 预览页。要求手机竖屏与电脑都能良好渲染，可一键截图传播。

## 内容与结构

版面自上而下分为三层：

1. 顶部为 Dashboard 仪表盘。先用一句话点明这份研报最锋利的核心结论，要求是洞察而不是复述。下方并排展示 4–6 张关键指标卡片，覆盖评级、目标价及上调幅度、当前价、隐含涨跌空间，以及最核心的 1–2 个业务数字。所有数字必须精确，并带单位、货币与时间锚点。
2. 中部为重点数据与逻辑要点。用简洁条目或小表呈现估值、增长驱动、催化剂、风险，全部源自 PDF 原文，绝不编造，绝不遗漏关键项。
3. 底部留一行原始信源与日期。

原文未提供的指标明确标注“原文未提供”，不要补造目标价、上调幅度或估值。区分事实、管理层表述、供应链预期与分析师判断，保留原文的时间范围及限定条件。

## 视觉与篇幅

设计追求书法级的克制美感：中文标题用思源宋体一类衬线体，正文用无衬线体；大量留白、精确网格对齐；浅色背景搭配深蓝与浅蓝，辅以极少量强调色。禁用花哨渐变、阴影、emoji 与红绿乱撞。

全文篇幅严格控制在约一页 A4 之内，最多不超过一页半。宁可精炼，也要覆盖所有关键信息，做到一眼看懂、越看越有料、越像一件作品。

## 交付

最终只交付这一个 HTML 文件，用 `present_files` 预览，不加任何标题、字数说明或解释。
