# 内容与视觉

原始提示词以项目 prompts/研报单页HTML解读.md 为准，用户当次要求优先。项目默认浓缩为约 1 页 A4、最多约 1.5 页，同时保持手机阅读；不要为了压缩把字号缩到难以阅读。

- 核心结论是有证据支持的洞察，避免把推演写成事实。
- 顶部关键指标 4–6 项覆盖评级、目标价及变化、报告股价、涨跌空间、业务数字；无关的指标不强行套入行业/宏观报告。原文缺项写“原文未提供”，不以联网当前行情替代历史报告数据。
- 检查公司、股票代码、币种、单位、基期、同比/环比、财年/自然年、现价日期和目标价期限；明确区分百分点与百分比。
- 计算出的涨跌空间标注“据原文数据计算”；没有现价或目标价不计算。保留预测年份与供应链/管理层/分析师判断的主体。
- 中部覆盖数据、估值、驱动、催化和风险。只在相关时列公司评级；不虚构额外的独立投资建议。
- 冲突数字回看图表标题、正文与脚注，不擅自挑选更好看的数值；保留差异或说明无法核对。
- 底部列机构、报告原题、原报告日期。页面明确为解读，不伪装成机构官方原件。

采用现有报告风格：外背景 #eef2f5，页面 #fbfcfd，深蓝 #153550、正文 #334b5e、辅助 #698092、分隔线 #d5e0e7、浅蓝块 #eaf2f7。标题宋体，正文中文无衬线；无渐变、夸张阴影或装饰 emoji。保留打印样式。需要截图按钮时沿用已有报告的本地 html2canvas 实现，移除旧报告硬编码的标题/下载名；不可引用私有路径或依赖不可用的 CDN。

先读全文再浓缩；长篇可分批提取但不得仅看摘要。PDF 阅读可使用当前环境可用的 PDF 技能、Poppler 或 Python 库；若不能可靠识别关键表格，报告局限并停止未经核实的数据发布。
